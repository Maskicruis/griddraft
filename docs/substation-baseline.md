# 升压站默认网络基准

后续新增或调整的升压站默认网络，统一依据用户提供的 `00126.xlsx`。它是项目进度参考，不代表国家或行业标准。

## 已确定的规则

- 工程划分、工作名称、具体工序、工期（工日）及计划开始／完成日期以该表为基准。项目调整应保留原始基准与调整记录。
- 前置／后置工作中的数字是**原计划软件的工作编号**，用户已明确确认；它们不是 Excel 行号。
- 汇总工作与明细工序分开处理，避免把父级跨度和子级工期累计计算。重复模块折叠仅改变显示，保留完整明细及跨模块控制关系。
- 原表的 SS、FS、时滞、日历时间与工日含义需要保持。现有计算引擎的非负时滞 FS 关系不能冒充对原表全部关系的支持。
- 不再把旧版七道工序、每道一天的升压站骨架当作本表的实现。已有用户图文件保持其已保存的内容，新增默认模板通过校验后替换。

## 尚未激活自动计算默认模板的原因

当前导出没有工作编号列，无法验证编号到记录的映射；部分关系包含省略或疑似不完整文本，例如 `C143`。出现编号207本身不是错误，它表示原软件编号可能不连续，不能据此改成行号。

需要补充带**原工作编号**、完整前后置关系的导出；如原软件支持，应同时保留父工作编号／层级和工作日历。通过编号、引用完整性、关系类型、层级和时间核对后，才能准确替换可计算的默认网络。
