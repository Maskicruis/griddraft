### 计划智能体

接入官方 DeepSeek Harness。智能体可使用 GridDraft 工具查询工序和关键线路、试算工期，并流式显示结果。试算先形成草稿，审阅后可应用到当前计划并撤销。

### 设置与启动

- 「模型配置」支持 DeepSeek 官方 API 和 OpenAI 兼容 API，提供连接测试与加密保存。SiliconFlow 的地址可填 `https://api.siliconflow.cn/v1`，模型 ID 以平台显示为准。
- 「软件更新」检查 GitHub 正式版本、下载并校验新版 EXE。下载完成后可打开文件位置，保存当前工作后手动运行新版。
- 「第三方插件」预留后续集成位置。Windows 便携 EXE 已使用 GridDraft 图标。

### 快速试用

下载 EXE 后打开自带的扶余演示。在模型配置成功后，在「计划智能体」输入「把进场道路工期改成 10 天，试算总工期」。试算结果应为 35 天，原始计划 34 天。点击应用才会更新图纸。
