# GridDraft V0.5.2

加入Excel计划导入、时标图自适应布局，以及类似Archify连接流动效果的箭线动画。

## Excel

- 左侧或项目概况窗口进入“导入 Excel 计划”，直接选择 `.xlsx`。
- 完整记录预览、工作表选择、字段映射、最近一次导入恢复、原始资料保存。
- 按原工作编号建立关系，明确识别汇总行；阻止重复编号、缺失引用、循环、截断或不支持的关系生成错误计算图。
- 原日期与原始记录随成功生成的源图保存，保留后续核对依据。当前计算仍支持FS及非负整数天时滞，未导入原软件工作日历。

## 自动布局与动画

- 时间轴保持等比例，按并行工序和当前窗口选择尺度，文字自动换行、避让，邻近事件错层。
- 初次显示及窗口变化自动适配，大图保留可读比例并支持滚动；提供智能适配、实际大小和全图缩略。
- 时标图、结构图和模块总览加入流动箭线开关，可暂停，遵循系统减少动态效果设置。动画只表达依赖方向，不表示实际进度；导出保持静态。

## 快速测试

1. 下载 `GridDraft-Desktop-0.5.2-x64.exe` 并直接运行。
2. 点击“导入 Excel 计划”，选用附件 `GridDraft-Excel-Plan-Example.xlsx`。
3. 校验通过后生成网络，切换到“双代号时标”，查看智能布局和流动箭线。
4. 点击“流动箭线”暂停，再用“实际大小／全图缩略”检查布局。

升压站参考表 `00126.xlsx` 可以读取全部191条记录。原软件编号列和部分完整关系仍需补齐；此版本不会凭Excel行号猜测连线，也未宣称该参考网络已完整还原。原表保留在本地，没有公开上传。
