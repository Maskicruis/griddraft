### 上下文对话编辑整张网络图

计划智能体新增整图创建、工序与连线增删、重命名、移动、时滞调整、草稿撤销等工具。同一会话持续保留前文和工具结果，可结合当前选中的工序、连线或事件理解后续请求。

修改会累积在同一份草稿中，支持预览、应用和撤销。外部手工编辑后，过期草稿会停止应用，后续请求会以当前正式图为准。

### 用对话操作软件

可请求切换双代号时标图、结构图、流程编辑、工作表和时间轴，定位工序或连线，自动排版，打开、保存、另存以及导出 SVG / 事件 JSON。图纸打开与导出会沿用文件选择对话框。

### 连续操作示例

1. 打开扶余示例，配置支持工具调用的模型。
2. 提问「在进场道路和钻孔灌注桩之间插入质量验收，工期 2 天」。
3. 继续提问「把刚才新增的那道改成 4 天，名称改为道路验收，并展示工作表」。
4. 点击预览，核对后应用草稿。示例总工期由 34 天变为 38 天，工作表中会出现新增工序。撤销可恢复原图。
