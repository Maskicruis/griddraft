GridDraft 首个公开版。桌面端和 CLI 共用同一个施工进度网络计算引擎，支持双代号时标图、逻辑结构图、工作时差表、SVG 和事件 JSON 导出。

### 快速开始

1. 下载并运行 `GridDraft-Desktop-0.2.0-x64.exe`。启动后会打开扶余演示，先查看默认的「双代号时标」，再切换到「双代号结构」检查工序依赖。
2. 在「双代号工作表」点击「进场道路」，将工期从 9 天调整为 10 天。示例总工期应由 34 天变为 35 天。撤销后可继续使用原示例。
3. 批量制图时，解压 `GridDraft-CLI-0.2.0-windows-x64.zip`，在解压目录运行下面的命令。

```powershell
.\griddraft.cmd network .\examples\fuyu-demo.json --view time --out fuyu.svg
.\griddraft.cmd network .\examples\fuyu-demo.json --format json --out events.json
```

附件还包括示例时标图、操作指南和 SHA-256 校验值。源码按 MIT 许可证开放。示例工期为演示值，本版计算使用完成到开始关系和非负时滞。
