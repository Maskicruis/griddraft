# GridDraft V0.5.1

新增重复模块汇总与点击跳转。项目包含多台相同风机或相同线路模块时，总图不再铺开所有工序。

- 生成或打开项目时自动识别重复单位工程并显示模块总览。工序结构、名称、工期、时滞、来源和外部衔接全部一致才合并；改动后的实例单独分组。画布坐标不影响判断。
- 汇总节点显示数量、编号范围、工序数和源网络时间范围。点击进入代表工程，下拉框切换其他实例，支持键盘 Enter / 空格进入和一键返回总览。
- 保留受电、并网等外部控制点，必要时把同一模块分段显示。原始工序和关系完整保存，工期和关键线路按完整源网络计算。
- 支持导出汇总 SVG、CLI `summary` SVG / JSON，以及智能体查询分组和切换总览。SVG 为静态展示，交互跳转在桌面软件内使用。

## 快速使用

1. 下载 **GridDraft-Desktop-0.5.1-x64.exe**，直接运行，无需安装 Node.js。
2. 从项目信息窗口输入如“27台风机、1座升压站、3回集电线路”，确认数量和模板后生成。
3. 点击「风机 · 27个重复模块」进入 WT01；通过单位工程下拉框查看 WT02 等实例。
4. 点击「返回模块总览」回到总图。需要完整展开时选择双代号结构或时标视图。
5. 保存 JSON 保留所有工序及模块信息；旧版本 JSON 可继续打开。

默认 1 天工期仍为待估算占位值。没有单位工程标记的普通图不会仅按名称自动合并。资源、天气和日历尚未参与工期计算。

## 附件

- Windows EXE：带应用图标的便携桌面程序。
- CLI ZIP：包含 Node.js、依赖、示例和命令入口。
- GridDraft-Module-Summary-Example.svg：27 台风机项目的汇总图，可直接查看。
- GridDraft-Project-Network-Example.json：保留完整工序的同一项目，可在桌面版中打开并测试跳转。
- QUICKSTART.md：使用说明。
- SHA256SUMS.txt：下载附件校验清单。
